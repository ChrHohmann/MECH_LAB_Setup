# 5. Persönlichen Fork erstellen

## Ziel

Nach dieser Seite besitzen Sie unter Ihrem GitHub-Konto eine persönliche Kopie des Labor-Repositories mit dem Namen MECH_LAB.

## Voraussetzungen

- ein angemeldetes und bestätigtes GitHub-Konto.

## Was ist ein Fork?

Ein Fork ist eine eigenständige Kopie eines Repositories. Das Original der Modulverantwortlichen heisst später **upstream**. Ihr persönlicher Fork heisst **origin**. Sie können Änderungen in Ihren Fork laden, ohne das Original zu verändern.

## Fork erstellen

> **Vor Veröffentlichung anpassen:** Ersetzen Sie den folgenden Platzhalter durch den direkten Link zum Labor-Repository.

1. Öffnen Sie [das Labor-Repositor](https://github.com/ChrHohmann/MECH_LAB).
2. Prüfen Sie, dass Sie angemeldet sind.
3. Klicken Sie oben rechts auf **Fork**.
4. Wählen Sie Ihr persönliches Konto als **Owner**.
5. Tragen Sie bei **Repository name** ein:

       MECH_LAB

6. Behalten Sie die übrigen Standardeinstellungen bei.
7. Klicken Sie auf **Create fork**.
8. Warten Sie, bis GitHub den Fork erstellt hat.

## Kontrolle

Oben links muss stehen:

    IhrGitHubBenutzername/MECH_LAB

Verwechseln Sie die Repositories nicht:

- ChrHohmann/MECH_LAB_Setup enthält diese Anleitung.
- IhrGitHubBenutzername/MECH_LAB enthält Ihren Laborcode.
