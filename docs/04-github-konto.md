# 4. GitHub-Konto erstellen

## Ziel

Nach dieser Seite besitzen Sie ein persönliches GitHub-Konto mit bestätigter E-Mail-Adresse.

## Voraussetzungen

- Zugriff auf Ihre HSLU-E-Mail-Adresse und
- ein Webbrowser.

Falls Sie bereits ein geeignetes persönliches GitHub-Konto besitzen, melden Sie sich an und gehen Sie direkt zur Kontrolle.

## Konto erstellen

1. Öffnen Sie [github.com/signup](https://github.com/signup).
2. Tragen Sie Ihre HSLU-E-Mail-Adresse ein.
3. Legen Sie ein sicheres, einzigartiges Passwort fest.
4. Wählen Sie nach Möglichkeit einen Benutzernamen nach dem Schema:

       vornamenachname-hslu

   Beispiel: maxmuster-hslu.

5. Folgen Sie den Anweisungen.
6. Öffnen Sie die Bestätigungsnachricht im HSLU-Postfach.
7. Bestätigen Sie Ihre E-Mail-Adresse.
8. Melden Sie sich bei GitHub an.

## Sicherheit

Aktivieren Sie nach Möglichkeit die Zwei-Faktor-Authentifizierung. Verwenden Sie niemals Ihr Laborpasswort als GitHub-Passwort.

## Kontrolle

1. Öffnen Sie oben rechts Ihr Profilmenü.
2. Prüfen Sie den angezeigten Benutzernamen.
3. Öffnen Sie **Settings → Emails**.
4. Prüfen Sie, ob die E-Mail-Adresse bestätigt ist.

Öffnen Sie [Fehlerbehebung](11-fehlerbehebung.md).
