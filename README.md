# MECH_LAB_MM – Entwicklungsumgebung einrichten

Mit dieser Anleitung richten Sie Ihren Computer für die Laborübungen ein.
Planen Sie ungefähr 45 bis 60 Minuten ein.

## Bevor Sie beginnen

Sie benötigen:

- einen Computer mit Windows oder macOS,
- Administratorrechte,
- eine stabile Internetverbindung,
- Ihre HSLU-E-Mail-Adresse und
- später Zugang zum Labor-WLAN und zu einem Raspberry Pi.

Führen Sie alle Schritte in der angegebenen Reihenfolge aus. Gehen Sie erst
weiter, wenn die Kontrolle am Ende einer Seite erfolgreich ist.
